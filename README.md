# Mobile & Laptop Sales Dashboard – Power BI

An interactive Power BI dashboard analyzing mobile and laptop sales data across brands, regions, and product specifications.

---

## Dashboard Overview
- Total Revenue: 28bn | Sum of Price: 5bn | Max Price: 200K | Avg Price: 103K
- Revenue split: Laptop 50.17% vs Mobile 49.83%
- Revenue by Brand and RAM specifications
- Quantity Sold by Brand (Google, Nokia, Apple, Sony, Samsung and more)
- Price breakdown by Product, Brand, SSD, and ROM

---

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling
